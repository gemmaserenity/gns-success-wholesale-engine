## Data Principles

Every imported datum should preserve:

- source
- source identifier when available
- retrieval timestamp
- original value
- normalized value
- confidence
- provenance

Data should distinguish between:

- verified
- public record
- estimated
- model-derived
- seller-reported
- human-verified

The system should not depend on brittle unauthorized scraping.
